# Sajal Bajracharya Portfolio

Responsive portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and GSAP.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Production

```bash
npm run build
npm run start
```
